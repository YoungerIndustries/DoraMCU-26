# S05: Lightning Class Cruisers — Rules Extraction

## Source
Classic Traveller Supplement 5: Lightning Class Cruisers (1980), GDW
Design: Loren K. Wiseman
Originally available only in the Azhanti High Lightning (G03) boardgame box set
Not sold individually as a supplement

## Overview
Supplement 5 provides detailed treatment of the 60,000-ton Azhanti High Lightning (AHL) class interstellar cruisers. It was included only with the Azhanti High Lightning boardgame and was never sold separately. The supplement contains history, deck plans, service histories, and High Guard statistics for the iconic Lightning-class cruisers.

### Contents
1. Lightning-class cruiser history and production run
2. Service histories of individual ships
3. Detailed deck plans (14 deck plan sheets)
4. High Guard combat statistics
5. Ship systems and components
6. Crew organization and requirements

## Lightning-Class Cruiser Overview

### General Specifications
- **Class Name**: Azhanti High Lightning (AHL)
- **Tonnage**: 60,000 tons
- **Type**: Frontier Cruiser
- **Decks**: ~84 decks
- **Role**: Multi-purpose cruiser for frontier operations
- **Operator**: Third Imperium Navy, frontier deployments

### Design Philosophy
- Frontier cruiser designed for independent operations
- Balanced armament for various combat scenarios
- Extended range and endurance for frontier deployments
- Modular design allowing mission-specific configuration
- Named after Imperial battles and victories

### Production History
- Multiple ships built over extended production run
- Each ship named individually
- Production distributed across Imperial shipyards
- Ships assigned to frontier sectors and strategic positions
- Service histories vary by individual vessel

## Deck Plans

### Deck Arrangement
The AHL-class cruiser has approximately 84 decks with the following key areas:

- **Bridge**: Command and control center
- **Avionics**: Multiple avionics spaces (decks 2-4, 6-7, 9)
- **Cartography**: Navigation and mapping (decks 5, 8)
- **Lounge**: Crew recreation areas
- **Engineering**: Drive and power systems
- **Hangar**: Fighter and small craft operations
- **Troops**: Marine and troop accommodations
- **Cargo**: Supply and equipment storage
- **Living Quarters**: Crew accommodations across multiple decks

### Deck Plan Sheets
- 14 double-sided deck plan sheets included in original box
- Detailed room-by-room layouts
- Used for tactical combat and boarding actions
- Scale suitable for miniature or counter-based combat
