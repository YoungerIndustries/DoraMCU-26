## HOW TO SUBMIT YOUR CHARACTER

### Option 1: API Submission
Submit your completed character sheet via the DoraMCU REST API:

```
POST /api/v1/traveller/characters?name=CharacterName
POST /api/v1/shared-characters
POST /api/v1/dnd5e/characters
POST /api/v1/captains-log/characters
```

### Option 2: Game Master Review
Print this sheet, fill it out by hand, and submit it to your Game Master for review and integration into the galaxy.

### Option 3: JSON Import
Export your character as JSON using the schema at `docs/character-sheet-schema.json` and import via the unified characters endpoint.
