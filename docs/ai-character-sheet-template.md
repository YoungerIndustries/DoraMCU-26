## HOW TO SUBMIT YOUR AI CHARACTER

### Option 1: API Submission
```
POST /api/v1/shared-characters
Content-Type: application/json

{
  "identity": { "name": "Character Name", ... },
  "characterType": { "type": "ai", ... },
  "aiConfig": { ... }
}
```

### Option 2: JSON Import
Export your character as JSON using the schema at `docs/character-sheet-schema.json` and import via the unified characters endpoint.

### Option 3: Game Master Review
Print this sheet, fill it out by hand, and submit it to your Game Master for AI neuron integration.
